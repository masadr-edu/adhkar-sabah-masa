# موقع أذكار الصباح والمساء 🌙

موقع ثابت (HTML + CSS + JS) لعرض أذكار الصباح والمساء الصحيحة موثقة بالمصادر، مع مسبحة إلكترونية وتحكم بحجم الخط والثيم (ليلي/نهاري).

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
الموقع جاهز للنشر — فقط ارفع الملفات إلى فرع `main` وفعّل Pages من الإعدادات (المصدر: Deploy from a branch / root).

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيقات
- `adhkar.js` — بيانات الأذكار مع المصادر
- `app.js` — التفاعلية
